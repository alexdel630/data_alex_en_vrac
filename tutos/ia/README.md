# Travailler efficacement avec l'IA générative

Série de tutoriels pour ingénieurs et chefs de projet qui veulent utiliser les assistants d'IA générative (assistants conversationnels, copilotes de code, agents) de façon **efficace, fiable et sûre**.

Les contenus sont neutres vis-à-vis des fournisseurs. Les produits évoluent très vite : quand une information dépend d'un outil précis, elle est volontairement générique ou datée (« en 2026 »). Vérifiez toujours la documentation à jour de l'outil que vous utilisez.

## Les 5 règles d'or

1. **L'IA propose, vous disposez** : vous restez responsable de ce que vous publiez ou livrez.
2. **Contexte > formule magique** : un bon prompt, c'est surtout un bon contexte.
3. **Rien de confidentiel sans autorisation** : respectez la politique de votre organisation.
4. **Jamais de secret dans un prompt** : mots de passe, clés API, tokens restent hors de l'IA.
5. **Vérifiez tout ce qui compte** : chiffres, références, code, engagements.
